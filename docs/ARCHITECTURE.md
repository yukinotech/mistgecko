# MistGecko 架构

## 当前产品方案

采用方案 A：单个完整离线 APK 内置 LaMa，用户无需下载/导入模型，也无需 ADB。正式发布 ARM64 `aiRelease`；`demo` 只保留为非 AI 交互调试工具。

- Kotlin + Android 原生 Canvas；Android 10+。
- ONNX Runtime Android 1.23.2，CPU 推理。
- Carve LaMa FP32 ONNX 固定版本，实际带动态维度声明，App 始终构造 512×512 输入。
- 应用无 INTERNET 权限，不上传图片、不依赖推理服务器。

## 分层

```text
MainActivity                  交互编排、单后台线程、忙碌锁与失败反馈
  ├─ EditorView               等比显示、画笔坐标转换、笔画 undo/redo、对比
  ├─ ImageStore               SAF 图片解码、MediaStore 原尺寸 PNG 导出
  └─ InpaintPipeline          原图遮罩 → 上下文 ROI → 512 输入 → 遮罩内回填
       └─ InpaintEngine       可关闭的本地推理接口
            ├─ ai             内置 LaMa、模型准备与校验、ONNX CPU
            └─ demo           传统扩散填充，只用于交互调试
```

## 模型生命周期

构建时 `scripts/prepare_model.py` 按 `model.lock.json` 的固定 revision 下载模型，核对大小与 SHA-256，再原子写入 AI 专属 assets。Gradle 的 AI 构建任务也检查哈希，禁止生成缺模型包。权重不进 Git，CI 可校验后复用缓存。

模型元数据一同打包。运行时根据哈希命名私有目录模型，首次消除时从 APK 复制到临时文件，校验后重命名，成功后才清理旧模型。失败时删除临时文件，下次可重试。模型升级由新 APK 驱动，清除数据后也能直接从 APK 恢复。

模型在 APK 中以不压缩资源保存，同时存在一份私有运行副本，需要额外磁盘空间。后续可研究直接读取 assets 或内存映射，避免重复占用；当前选择文件加载以保持生命周期简单。

## 图像管线

1. ImageDecoder 软件解码并应用图片方向；超过 1200 万像素明确拒绝，不悄悄缩小原图。
2. 原尺寸遮罩白=消除，黑=保留；显示画笔转换到原图坐标。
3. 遮罩非黑包围盒扩展至最长边的 1.6 倍，最低 64 像素的正方形上下文。
4. 图像和遮罩等比裁剪至 512×512；越界部分填黑，遮罩最近邻采样。
5. LaMa 输入 RGB float NCHW / 255，推理遮罩额外膨胀 8 个模型像素，避免缩放后物体颜色残留。
6. 模型输出 RGB NCHW / 0–255，双线性采样回原图，按原始遮罩覆盖率合成；只修改原遮罩非零像素。
7. MediaStore pending 写入 PNG，成功才公开相册记录，失败清理。

黑边上下文可能影响靠边修复。远距离多个目标共用一个 ROI，极细笔画也可能在缩放中丢失；后续可引入反射 padding、连通域拆分、分块和遮罩保护策略。

## 状态与资源

解码/模型准备/推理/保存使用单线程 Executor，忙碌时锁定编辑。每次推理显式关闭 Session、Tensor、Result；旧图片与结果 Bitmap 在替换时释放，保留原图供对比。Android 12+ 声明排除系统云备份与设备迁移。

当前无缩放平移、多步结果历史、推理取消或进程死亡恢复。系统文件选择器可能显示云端供应商，完全离线时需选择本机照片。

## 验证记录（2026-10-21）

- JDK 17、SDK 35、Gradle 8.14、AGP 8.11.1、Kotlin 2.2.20。
- AI 和 Demo 调试包已构建并完成 Lint；ONNX Runtime 1.23.2 不再产生之前 1.20.0 的 16 KB 对齐警告。
- 设备型号 25060RK16C 已实际运行真实 LaMa。合成图完整链路约 15.27 秒，6161 个遮罩内像素被修改，遮罩外逐像素一致；扩展推理 mask 后红边消除。图像证据在 `docs/validation/`。
- 早期真机验证采用 ADB 写入模型；当前正式方案已改为内置权重，不能把旧测试称为新版干净安装验收。
- 首个完整正式签名包约 230 MB；本机构建脚本检查模型哈希、ABI、许可证与签名，Release Lint 通过。
- 准备验证内置权重的新独立测试包时手机已从 ADB 断开；新版无预置模型的真机验收仍待执行。
